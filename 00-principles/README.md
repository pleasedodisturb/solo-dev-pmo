# 00 — Principles

Four design axes that shape every chapter. Read these first.

| Principle | One-liner |
|---|---|
| [ADHD-aware design](./adhd-aware-design.md) | Affordances, not discipline. The system enforces; the human doesn't have to remember. |
| [4-layer memory architecture](./four-layer-memory.md) | Global rules / project rules / auto-memory / cross-project memory. Each layer has a job; don't mix them. |
| [Single source of truth](./single-source-of-truth.md) | One inbox. One capture surface. One canonical doc per topic. Duplication is debt. |
| [Calendar-vendor-neutrality](./calendar-neutrality.md) | Time layer must work without Google or Apple. Plaintext + ntfy + iCal export. |

If you only read one, read [ADHD-aware design](./adhd-aware-design.md) — it's the axis that distinguishes this playbook from every adjacent one.
